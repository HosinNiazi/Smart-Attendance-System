# حضوربان | فرانت‌اند سامانه حضور و غیاب هوشمند

رابط کاربری فارسی و راست‌چین با React، Vite و Bootstrap 5 RTL. این پروژه در حال حاضر فقط فرانت‌اند و داده‌های نمونه دارد؛ ورود، ثبت دانشجو و تغییر وضعیت حضور در همین نسخه به‌صورت نمایشی انجام می‌شوند. تشخیص چهره واقعی هنوز به بک‌اند یا مدل هوش مصنوعی متصل نیست.

## پیش‌نیاز
- Node.js نسخه 20 یا جدیدتر (پیشنهادی)
- npm

## اجرا در ویندوز
1. فایل ZIP را استخراج کنید.
2. در پوشه پروژه، ترمینال را باز کنید.
3. دستورات زیر را اجرا کنید:

```bash
npm install
npm run dev
```

4. آدرسی را که Vite نمایش می‌دهد، معمولاً `http://localhost:5173`، در مرورگر باز کنید.

## ساخت نسخه نهایی

```bash
npm run build
npm run preview
```

## بخش‌ها
- ورود نمایشی مدیر
- داشبورد آماری
- مدیریت دانشجویان با افزودن، جست‌وجو و حذف
- درس‌ها و جلسات
- ثبت دستی حضور، تأخیر و غیبت
- صفحه دوربین با `getUserMedia` و ثبت حضور آزمایشی (بدون تشخیص چهره واقعی)
- گزارش‌ها و خروجی CSV
- تنظیمات نمایشی

## نکات
- اطلاعات در حافظه برنامه هستند و با رفرش صفحه به نمونه اولیه برمی‌گردند.
- دسترسی به وب‌کم معمولاً روی `localhost` یا HTTPS کار می‌کند و نیاز به اجازه مرورگر دارد.
- برای نسخه واقعی باید API بک‌اند، احراز هویت، SQL Server و سرویس تشخیص چهره به این رابط متصل شوند.
