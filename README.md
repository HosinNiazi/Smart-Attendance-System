## معرفی پروژه

**حضوربان (Hozorban)** یک سامانه تحت وب برای مدیریت فرآیند حضور و غیاب در محیط‌های آموزشی است که با هدف ساده‌سازی مدیریت کلاس‌ها، دانشجویان، جلسات آموزشی و سوابق حضور طراحی شده است.

این سامانه با رویکرد توسعه یک سیستم هوشمند مبتنی بر فناوری‌های وب و هوش مصنوعی طراحی شده و بستری برای مدیریت متمرکز اطلاعات آموزشی، ثبت وضعیت حضور و غیاب، تهیه گزارش‌های آماری و استفاده از قابلیت‌های مبتنی بر دوربین فراهم می‌کند.

نسخه حاضر شامل رابط کاربری فرانت‌اند، صفحات مدیریتی و داده‌های نمونه است. عملیات مدیریتی و ثبت حضور در این نسخه به‌صورت نمایشی انجام می‌شوند و هنوز به سرویس واقعی بک‌اند، پایگاه داده یا موتور تشخیص چهره متصل نیستند.

## امکانات و قابلیت‌ها

### ۱. مدیریت و داشبورد
- صفحه ورود نمایشی مدیر
- داشبورد مدیریتی با نمایش آمار کلی
- نمایش وضعیت دانشجویان و جلسات
- دسترسی سریع به بخش‌های مختلف سامانه

### ۲. مدیریت دانشجویان
- افزودن دانشجوی جدید
- مشاهده فهرست دانشجویان
- جست‌وجو و مدیریت اطلاعات
- حذف دانشجویان از فهرست
- نمایش اطلاعات دانشجویان

### ۳. مدیریت دروس و جلسات
- نمایش فهرست دروس
- مدیریت اطلاعات جلسات آموزشی
- مشاهده وضعیت جلسات
- سازمان‌دهی اطلاعات کلاس‌ها

### ۴. مدیریت حضور و غیاب
- ثبت دستی وضعیت حضور دانشجویان
- ثبت وضعیت غیبت و تأخیر
- تغییر وضعیت حضور
- نمایش سوابق و اطلاعات حضور و غیاب

### ۵. بخش دوربین و حضور هوشمند
- دسترسی به دوربین دستگاه با استفاده از Web API
- استفاده از قابلیت `getUserMedia`
- نمایش تصویر زنده دوربین در مرورگر
- شبیه‌سازی فرآیند ثبت حضور

> توجه: در نسخه فعلی، شناسایی هویت افراد با الگوریتم واقعی تشخیص چهره انجام نمی‌شود. نمایش دوربین و ثبت حضور آزمایشی صرفاً برای آماده‌سازی رابط کاربری این بخش در نظر گرفته شده‌اند.

### ۶. گزارش‌ها
- نمایش اطلاعات حضور و غیاب
- مشاهده گزارش‌های آماری
- خروجی گرفتن از اطلاعات در قالب CSV

### ۷. تنظیمات
- صفحه تنظیمات سامانه
- نمایش گزینه‌های مدیریتی
- آماده‌سازی رابط تنظیمات برای اتصال به سرویس‌های واقعی

## فناوری‌ها و ابزارهای استفاده‌شده

| فناوری | کاربرد |
|---|---|
| React | توسعه رابط کاربری مبتنی بر کامپوننت |
| JavaScript | پیاده‌سازی منطق سمت کاربر |

| Bootstrap 5 | طراحی ساختار و اجزای رابط کاربری |
| Bootstrap RTL | پشتیبانی از چیدمان راست‌چین |
| HTML5 | ساختار صفحات |
| CSS3 | طراحی و شخصی‌سازی ظاهر |
| MediaDevices API | دسترسی مرورگر به دوربین |
| CSV | خروجی گرفتن از اطلاعات گزارش‌ها |
| npm | مدیریت وابستگی‌های پروژه |

## پیش‌نیازهای اجرا

برای اجرای پروژه به ابزارهای زیر نیاز دارید:

- **Node.js:** نسخه 20 یا جدیدتر
- **npm:** مدیر بسته Node.js
- یک مرورگر به‌روز مانند Google Chrome یا Microsoft Edge
- اتصال اینترنت برای نصب اولیه وابستگی‌ها

## نصب و راه‌اندازی در ویندوز

### مرحله اول: دریافت پروژه

مخزن پروژه را دریافت کنید یا فایل ZIP آن را دانلود و استخراج کنید.

```bash
git clone https://github.com/HosinNiazi/Smart-Attendance-System.git
```

سپس وارد پوشه پروژه شوید:

```bash
cd Smart-Attendance-System
```

### مرحله دوم: نصب وابستگی‌ها

در ترمینال و در مسیر اصلی پروژه دستور زیر را اجرا کنید:

```bash
npm install
```

### مرحله سوم: اجرای محیط توسعه

```bash
npm run dev
```

پس از اجرای موفق، Vite آدرس محلی پروژه را نمایش می‌دهد. معمولاً آدرس زیر در دسترس خواهد بود:

```text
http://localhost:5173
```

این آدرس را در مرورگر باز کنید.

## ساخت نسخه نهایی (Production Build)

برای ساخت نسخه بهینه‌شده پروژه دستور زیر را اجرا کنید:

```bash
npm run build
```

فایل‌های خروجی در پوشه `dist` قرار می‌گیرند.

برای مشاهده نسخه ساخته‌شده در محیط محلی:

```bash
npm run preview
```

> اجرای دستورهای بالا به وجود اسکریپت‌های مربوطه در فایل `package.json` وابسته است.

## ساختار عملکرد نسخه فعلی

در این نسخه، داده‌ها به‌صورت نمونه در محیط فرانت‌اند مدیریت می‌شوند.

- ورود کاربران به‌صورت نمایشی است.
- افزودن و حذف دانشجو در محیط رابط کاربری انجام می‌شود.
- تغییر وضعیت حضور و غیاب به بک‌اند ارسال نمی‌شود.
- داده‌ها در حافظه برنامه نگهداری می‌شوند.
- با بارگذاری مجدد صفحه، اطلاعات به وضعیت اولیه نمونه بازمی‌گردند.
- صفحه دوربین به API مرورگر متصل است، اما خروجی آن به موتور واقعی تشخیص چهره متصل نیست.

## دسترسی به دوربین

برای استفاده از قابلیت دوربین، مرورگر باید اجازه دسترسی به وب‌کم را دریافت کند.

دسترسی به دوربین معمولاً در شرایط زیر امکان‌پذیر است:

- اجرای برنامه روی `localhost`
- اجرای برنامه روی یک بستر امن HTTPS

در صورت نمایش درخواست مجوز، دسترسی دوربین را در مرورگر تأیید کنید.

اگر دوربین فعال نشد، اتصال وب‌کم، مجوزهای مرورگر و تنظیمات حریم خصوصی دستگاه را بررسی کنید.

## معماری توسعه‌یافته سامانه

معماری هدف حضوربان برای تبدیل شدن به یک سامانه هوشمند یکپارچه، از بخش‌های زیر تشکیل می‌شود:

| لایه | فناوری یا سرویس | مسئولیت |
|---|---|---|
| Frontend | React و Vite | رابط کاربری و تعامل با کاربر |
| Backend | Node.js و Express | منطق اصلی سامانه و API |
| Database | SQL Server | ذخیره‌سازی و مدیریت اطلاعات |
| AI Service | Python و FastAPI | پردازش تصویر و تشخیص چهره |
| Computer Vision | OpenCV و مدل تشخیص چهره | پردازش و تحلیل تصاویر |

این معماری، ساختار هدف سامانه را توصیف می‌کند و به معنی فعال بودن تمام ارتباطات در نسخه فعلی فرانت‌اند نیست.

## برنامه توسعه قابلیت‌های هوشمند

در معماری نهایی حضوربان، قابلیت‌های زیر برای تکمیل سامانه در نظر گرفته شده‌اند:

- اتصال فرانت‌اند به API بک‌اند
- پیاده‌سازی احراز هویت واقعی
- اتصال به پایگاه داده SQL Server
- ذخیره‌سازی دائمی اطلاعات دانشجویان و جلسات
- پیاده‌سازی سرویس تشخیص چهره
- استخراج و مقایسه ویژگی‌های چهره
- بررسی زنده بودن فرد (Liveness Detection)
- جلوگیری از ثبت حضور تکراری
- تأیید نتایج مشکوک توسط استاد
- توسعه گزارش‌گیری و مدیریت سوابق

## ملاحظات امنیتی و حریم خصوصی

با توجه به ماهیت اطلاعات سامانه، به‌ویژه اطلاعات هویتی و داده‌های بیومتریک، طراحی نسخه نهایی باید اصول زیر را رعایت کند:

- احراز هویت و کنترل سطح دسترسی
- حفاظت از اطلاعات کاربران
- نگهداری امن تصاویر و داده‌های چهره
- محدودسازی دسترسی به اطلاعات دانشجویان
- دریافت رضایت آگاهانه برای پردازش داده‌های بیومتریک
- ثبت رویدادهای مهم و فعالیت‌های مدیریتی
- امکان بررسی انسانی نتایج نامطمئن تشخیص چهره
